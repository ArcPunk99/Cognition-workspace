# 个人工作台理论框架：阶段性讨论成果

**日期：** 2026-11-28  
**性质：** 讨论成果整理稿；区分已明确共识、候选定义与开放问题。  
**范围：** 仅整理本轮关于意图域、信息域、行动域、Task、直觉及结束判定的讨论，不反向改写此前已确认的定义。

## 一、整体框架

围绕一个 Project 的总体目的，主体形成或调整意图，通过具体行动获取信息；信息可被进一步理解和判断，推动后续意图与行动。Task 是围绕具体目标组织这一过程的工作单元。

可用以下关系辅助理解（不是强制线性流程）：

**总体目的 → 意图 → Action → 原始信息 → 理解与判断 → 结论／意图调整 → 后续 Action**

行动完成、信息到达、结论形成、Task 结束是不同事件，不得自动等同。

## 二、意图域

**此前候选定义（原样保留）：**  
> 意图域是主体围绕总体目的，通过持续理解、判断与推演，不断形成和修正行动方向的意识活动领域。

意图解释主体为何开展探索、如何形成行动方向。关于“意识”“认知”的哲学区分，本轮仅作为开放讨论，不据此修改上述定义。

### 直觉与认知结构：开放假设

- 直觉可能来自既有经验与隐性模式识别，也可能来自面对未知时的创造性联想，即“灵光一闪”。
- 直觉可能促成假设和行动方向，但并不天然构成已证实结论。
- 本轮提出的进一步假设是：某些直觉背后隐含的认知结构可以逐渐显性化，并沉淀为类似 Ontology 的概念、属性及关系体系，而不只是增加一条 Knowledge。
- 严格意义上的 Ontology 与经验启发式、推理习惯并不完全重合，边界仍待讨论。

**状态：** 讨论假设，尚未纳入已确认定义。

## 三、信息域

**本轮明确的基本结构：两层。**

1. **原始信息（Raw）：** 外部材料、行动反馈等到达后的原始内容，保留来源及原貌；例如检索获得的十篇论文。
2. **结论信息（Conclusion）：** 主体在理解、分析、推理或验证之后形成的判断结论；结论不自动等同客观事实。

**候选定义：** 信息域是承载原始信息与认知结论的领域。

**重要边界：** 原始信息到达，不代表主体已经理解、认可或形成新结论。十篇论文检索完成后进入原始信息层；尚未阅读和判断时，不应自动生成结论层内容。

## 四、行动域与 Action

**当前候选定义：**  
> 行动域是主体在意图驱动下，为实现特定目标而直接实施或委托执行具体行为，并获得相应结果的活动领域。

本轮澄清：

- Action 是具体行为，具有独立的执行闭环；整个对话不是一个 Action，而可以是一个 Task。
- 在对话例子中，用户发出一条提示词属于 Action；AI 的回答对于当前探索主体而言属于反馈信息。
- 主体可以委托 AI 或其他执行者完成行动；是否为行动不能只看执行者身份，而应结合当前目标及过程角色。
- 行动执行结束不等于行动成功，也不等于产生新的认知判断。

**例子：** 为研究一个问题，用户发出检索十篇论文的指令；检索执行并交付资料后，该次行动闭环结束。十篇论文作为行动产生的信息成果进入 Raw，但 Task 仍可能继续，且尚未形成新的 Conclusion。

## 五、Task 与 Action 的层级关系

**候选表述：**  
> Action 是具有独立执行闭环的具体行为；Task 是围绕特定目标，组织意图、信息与多个 Action 持续交互的工作单元。

一个 Task 可以包含多次行动、多轮信息到达、理解与判断，以及意图调整。单个 Action 结束，不代表 Task 结束。

Task 的结束依据应取决于任务目标与人类最终判断，而非单纯统计已执行 Action 的数量或是否产生某条新结论。

## 六、Task 结束判定：本轮明确共识

**核心原则：系统可触发结束判断，人保留最终结束决定权。**

**第一层：系统 Trigger。** 系统依据预设 Workflow、完成条件或其他规则，识别可能达到结束条件的时机，并发出 Trigger。Trigger 是信号或建议，不是最终结束决定。

**第二层：人类判断。** 人结合任务目标、行动结果、已有认知与未解决问题，决定结束还是继续。

两条补充边界：

- 系统发出 Trigger 后，人可以拒绝结束并继续探索。
- 即使系统尚未发出 Trigger，人也可以主动判断并结束 Task。

因此，Task 的结束不等于 Workflow 自动完成；Trigger 与最终决策不是一对一绑定关系。

## 七、统一案例：检索十篇论文

1. **意图：** 研究某个理论问题，需要相关资料。
2. **Task：** 围绕该问题持续研究，尚未完成。
3. **Action：** 发出检索指令，委托 AI 检索十篇论文。
4. **Action 闭环：** AI 完成检索并交付资料。
5. **信息域 Raw：** 十篇论文进入原始信息层；目前没有自动产生新的判断结论。
6. **后续探索：** 阅读、比较、提出假设、验证，可能产生新的 Action 和 Conclusion。
7. **结束判定：** 系统可依据既定条件发出 Trigger，但只有人作出最终结束决定；人也可主动发起结束。

## 八、尚未收敛的问题

- 直觉、隐性经验、Knowledge 与 Ontology 的精确关系，以及认知结构如何演进。
- 意图域内部的思考与可识别 Action 的边界，在复杂场景中如何判别。
- Task 完成标准如何表达，以及不同目标类型是否需要不同标准。
- 系统 Trigger 的具体规则、状态机及技术实现（本轮不展开）。
