# 任务清单

P-003 个人工作台搭建2.0 的任务清单。每个 Task 有独立目录，目录里放 Task 记录和该 Task 下的 Action。意图表、原始资料库仍在项目级，用 ID 关联。

字段：id（稳定 ID）、所属项目、标题、目标、状态（待启动 / 进行中 / 暂停 / 已完成）、形成时间、任务目录。

Task 是更高一层的工作单元，围着一个 Task 目标，承载数个执行过程，直到这个目标实现。某个 Action 结束，不等于 Task 结束；Task 目标是否实现，须经人确认。
