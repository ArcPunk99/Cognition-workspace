# 意图表

P-003 个人工作台搭建2.0 的意图表。Trigger 不另开表，就是本表中状态为「候选」的行。

字段：id（稳定 ID，不随表述改）、所属项目（项目 ID）、意图本身、状态（候选 / 已转化行动 / 已完成）、目标（仅在已转化行动或已完成后填写，是这次 Action 的目的）、来源或依据（直觉引发的判断，或对话中暴露）、形成时间。

判断、产物不写入本表，各自成表，用本表 id 关联。产物须经人确认后才入库。

单轮循环：意图出现后先以候选（Trigger）入表；识别到人正在确认、对话仍在继续，或 Trigger 被确认，则转化为行动并生成目标；人说 OK，行动完成，输出产物片段，本轮结束。这不等于整个 Task 结束。
