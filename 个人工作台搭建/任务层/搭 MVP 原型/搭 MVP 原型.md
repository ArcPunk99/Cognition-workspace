# 搭 MVP 原型

**目的**　通过实际操作本地 H5 看板，弄清项目和任务怎样推进。

**来源与上下文**　承接 [[MVP 设计]]。首版本地看板已能读取 Project 仓库，以下需求来自扭老板试用后的语音讨论。

**目标**　跑通从项目看板进入项目、创建任务、查看该任务的资料，再到文档里确认一段内容的过程。

## 本轮试用需求 · 待实现

1. 项目看板与项目操作分成两页。点项目卡片进入该项目的操作页。
2. 点开具体任务后，在任务下查看与它关联的文档和资料，能看清本任务收进了哪些材料。
3. 用弹窗创建任务，写明目的或意图、触发任务的来源与上下文、希望完成的目标、当前状态。原型先支持手动创建，后续希望由 Agent 代建。
4. 阅读文档时选定起点和终点，为这段原文插旗，表示人已确认这段内容。第一版先实现手动选段和标记；是否进一步形成认知里程碑，留待后续流程处理。
