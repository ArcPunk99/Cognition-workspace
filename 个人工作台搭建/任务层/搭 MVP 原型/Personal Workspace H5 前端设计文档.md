# Personal Workspace · H5 前端设计文档

**实现快照｜2026-11-24**　所属任务 [[搭 MVP 原型]]。本文描述这一天的本地原型，供产品评审、继续开发和回归验证使用。项目对象与入库规则以 [[Schema]] 为准。

## 1. 产品定位与入口

人在项目中阅读资料、推进任务、确认认知成果。前端提供两种工作方式：在文档工作区处理眼前的材料，在任务画布里理解工作从哪里来、下一步去哪里。两种视图读取同一个 Obsidian 仓库。项目看板是入口，每张项目卡展示项目状态、任务总数和已完成数。

从看板选择项目进入项目页，顶部保留返回、项目名、分区、刷新仓库、记需求和创建任务。项目名菜单可访问仓库级文档。页面把项目、分区、任务、当前文档放入 URL 片段，支持直接打开某篇资料或某张任务卡。本机入口为 [项目看板](http://127.0.0.1:48732/)。

| 项目分区 | 左侧或画布展示 | 选中后的工作内容 |
| --- | --- | --- |
| 项目说明 | 项目根目录文档，优先 README | 阅读项目框架，通过 README 进入项目主对话 |
| 信息 | Raw 与认知 Milestone 两组，各有数量 | 阅读原文、标记选段、查看判断的依据；Raw 标题旁可批量添加链接 |
| 任务 | 任务名和状态；当前任务下展开关联资料 | 任务说明承载主对话，同目录文档及任务说明明确链接的资料可直接打开 |
| 产品 | 项目「产物层」中的文件 | 查看阶段成果。开发中的 H5 原型作为任务阶段产物保存在任务目录 |
| 任务画布 | Project 起点、任务卡片、父子曲线 | 点卡看详情，点关系看衍生原因，从卡片进入任务工作区 |

## 2. 文档工作区

桌面采用紧凑顶栏和三栏布局。左栏切换资料，中栏显示当前文档，右栏跟随文档切换会话。中栏正文独立滚动，标题、保存和选段操作留在上方。Markdown 直接编辑原文，PDF 在中栏内嵌查看，Bases 文件可查看源内容。

- **编辑与保存。** 编辑后启用保存按钮，支持 Ctrl/Cmd + S。切换文档时，未保存草稿临时留在当前页面。保存会比对原始内容；若 Obsidian 等其他程序已修改文件，页面提示冲突并保留草稿。
- **选段插旗。** 在已保存的项目 Markdown 中选取正文，点击「标记选段」。系统保存位置和摘录，可从标记清单定位；原文变化导致范围失配时会提示。标记表示选过这段材料，正式里程碑另有确认动作。
- **两张工作流卡。** 右栏上方约三分之一放「生成里程碑」「生成任务」，下方用于会话。卡片把请求和当前选段送入会话。「生成任务」预填来源并打开任务表单；在任务上下文的 Markdown 中，「生成里程碑」继续打开判断与引文确认表单。其他上下文可先留下请求。
- **小屏。** 文档工作区在宽度不超过 600 像素时，把右栏收为可打开的右侧抽屉。任务画布在这一宽度下改为上方画布、下方详情。

## 3. 会话与认知确认

打开文档时按需恢复会话，首次讨论由人主动开启。项目 README、任务说明和普通文档分别显示项目主对话、任务主对话和文档对话。从任务打开一份关联资料时，会话带上该任务上下文。用户可以另开主题、切回旧讨论、结束本次讨论。结束讨论与完成任务分别操作。

当前对话保存在本机浏览器。确认里程碑时，长期需要的判断和摘录写入项目的「信息层/认知里程碑」。从会话发起确认时，同时写入会话主题、标识和时间。从任务中的讨论消息可以直接确认该条内容。查看里程碑时可沿确认依据返回来源文档；同一浏览器保有对应会话时，可恢复到该次讨论。跨浏览器回看以仓库里的摘录为依据。

## 4. 任务画布与关系语义

点击「任务画布」，Project 根卡默认位于可视区域中央。顶层任务从根卡向右展开，子任务继续向右排列。直接打开指定任务的链接时优先定位该任务。按住空白处出现抓手，可上下左右平移；点击卡片、关系按钮和折叠按钮分别执行自身操作。

项目与顶层任务、父任务与子任务之间使用从卡边到卡边的三次贝塞尔曲线。任务间的「关系」按钮位于曲线中点，可查看父子名称、来源与衍生原因，以及明确记录的触发判断。展开、折叠和尺寸变化时重新计算可见曲线。

| 位置 | 展示与动作 |
| --- | --- |
| 项目根卡 | 项目名；选中后显示任务数、打开项目说明和创建任务 |
| 任务卡面 | 名称、状态、简短目标、本任务直接确认的里程碑数；有子任务时可折叠 |
| 右侧详情 | 工作意图、目标、状态、相关讨论、直接子任务、引用的判断、已确认里程碑及派生任务 |
| 任务操作 | 进入任务、新建子任务、关联已有独立任务、引用已有判断、确认新里程碑、从已确认里程碑派生任务 |

**四类关系分别回答四个问题。** 子任务的「父任务」说明它属于哪个目标；任务正文的「目的」和「来源与上下文」解释为什么做；里程碑的「所属任务」标明判断实际产生在哪里；新任务的「触发里程碑」标明是哪条判断促成了这项工作。其他任务可引用同一判断。卡面统计只取直接归属，直接子任务的成果在详情中按需展开。

任务状态沿用「待推进、进行中、已完成」。创建任务时填写名称、目的、来源与上下文、目标和状态，父任务可选。完成子任务、确认一条判断和结束讨论都由各自的操作触发。

**模拟案例。** 在上海到北京商务出行画布中，「确定交通方案」确认了航班和地铁接驳两条判断。「确定机场接驳方式」作为子任务继续核对地铁班次，引用已有判断。这样可以从子任务追到出行约束，也可以回到交通任务看到两条判断的原始归属。[打开模拟画布](http://127.0.0.1:48732/#p=上海到北京商务出行（模拟）&s=任务视图)

## 5. Raw 批量入库与反馈

在信息区选择「Raw → 添加」，粘贴论文、仓库或其他网页链接。页面检查链接格式并对本批地址去重，点击「开始转译」后逐条处理，逐项显示等待、转译中、已加入、已存在或失败原因。成功后刷新项目资料。

本地服务读取 Schema 中的网页入库规则，调用 DSH 获取正文。成功的 Markdown 进入当前项目 Raw，保留来源 URL、获取时间、实际转译原文和读取范围。凭据缺失、抓取失败或结果不完整时返回错误，用户可重新提交失败链接。真实网页转译依赖本机 DSH 的可用模型凭据。右侧文档会话当前提供本地讨论记录，尚未接入模型回复。

## 6. 视觉、持久化与实现位置

界面参考本机 Utopia 的默认暗色样式。背景采用近黑色，点阵标出可平移的画布；面板与卡片用灰阶分层，选中节点使用亮描边。进行中用琥珀色点、已完成用绿色点，同时保留状态文字。工作区以 14 像素正文和紧凑顶栏为主，让高度优先留给文档与任务树。

| 数据位置 | 保存内容 | 使用含义 |
| --- | --- | --- |
| Project 仓库 Markdown | 任务、状态、父子关系、确认后的里程碑、资料及引用 | H5 和 Obsidian 共读；刷新可重新取得外部修改 |
| 来源文档旁的标记文件 | 选段起止位置、摘录与时间 | 支持定位和识别已经变化的原文 |
| 浏览器 localStorage | 各文档及任务上下文的会话、讨论消息、当前会话 | 同一浏览器可恢复，清理站点数据会影响会话回看 |
| 当前页面内存 | 编辑草稿、折叠状态等 | 刷新前需要保存正文；画布按关系自动布局 |

前端由原生 HTML、CSS 和 JavaScript 构成，Node 本地服务读取仓库。页面布局和主题见 [index.html](H5看板/index.html)，导航、编辑、画布和会话逻辑见 [board.js](H5看板/board.js)，仓库读写和冲突校验见 [server.mjs](H5看板/server.mjs)，网页转译见 [raw-import.mjs](H5看板/raw-import.mjs)。入口为 [启动看板.cmd](H5看板/启动看板.cmd)。

## 7. 本版回归检查

1. 从项目看板进入项目，检查五个分区、Raw 与里程碑分组、任务下的关联资料；复制当前地址重新打开，应回到同一工作上下文。
2. 打开任务画布，检查根节点居中。拖动空白处、折叠再展开子树，曲线应随可见卡片更新；点「关系」应显示对应父子任务。
3. 从模拟案例的交通任务进入接驳任务，对照直接确认数和引用数；父卡汇总时能区分成果来源。
4. 在测试任务中开启两次讨论，结束其中一次，核对任务状态。确认一条消息后从里程碑回看原文，并检查仓库中保存的摘录。
5. 用测试笔记验证保存与外部编辑冲突；用一条已有 URL 和一条失败 URL 验证 Raw 导入反馈。缩窄窗口后检查会话抽屉、保存按钮和画布详情仍可达。
## 8. 2026-11-24 交接稿增补

任务工作区左栏的「添加任务资料」支持选择项目 Raw 中已有资料、上传原始 PDF 或 Markdown（含导出的外部对话与 Handoff），也可单独登记来源链接。原始文件保留字节内容，任务说明保存路径双链。单独登记的链接会标注「原文尚未获取」。在当前原型中优先复用项目内 Raw；跨项目存储布局仍待确定。

默认仅加入任务资料。选择「同时引用到当前讨论」会在当前文档与任务上下文的本地会话中加入可打开的资料引用。模型上下文的实际传送待接入 DSH 对话后验证。在信息区阅读项目 Markdown 时，可直接确认具有持续价值的判断，里程碑可仅关联来源，不强制绑定当前任务。
