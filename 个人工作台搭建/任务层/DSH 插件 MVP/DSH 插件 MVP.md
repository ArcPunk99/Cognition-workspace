# DSH 插件 MVP

**目的**　在工作台里用真实的单 Bot 会话推进任务，并保留判断所依据的原文。

**来源与上下文**　承接 [[搭 MVP 原型]]。项目、任务和资料继续由本地看板展示，Bot 的创建、角色和 Skill 由 DS Bot 原有页面管理。

**目标**　选中资料后能讨论原文、生成里程碑或任务草稿，并能切回同一讨论。最终判断由使用者确认。

## 当前试用 · v0.2

在 DSH 插件管理里选择 [工作台 v0.2 安装包](ds-bot-0.3.6-workbench.2.tgz)，重新加载后进入「工作台 → 项目总览」。从 README 主讨论开始探索，也可以打开任务说明，在任务上下文里继续。卡片随当前讨论切换。

有候选时，原生聊天上方显示「本次讨论的 Trigger」。展开卡片可以看原话、在同一会话继续讨论、创建任务、确认里程碑或忽略。成功写回后，卡片可打开结果。候选和澄清状态不会计入项目的正式产出。

字段说明与试验材料：[候选 Schema](Trigger%20Schema%20v0.2.json) · [[Trigger 行为与回放 v0.2]]。

## 历史试用 · v0.1

1. 启动 H5 看板。在 DSH 的插件管理中，从本地文件安装 [工作台插件包](ds-bot-0.3.6-workbench.1.tgz)，重新加载插件。
2. 进入 DS Bot 的 Bot 聊天页，点顶部「工作台」。左侧保留本地看板，右侧使用原生聊天。
3. 打开项目里的 Markdown 文档，选择已有 Bot，点「开始讨论」。文档和所属任务共同确定这次讨论，切回时可以继续。
4. 选中原文，点「生成里程碑」或「生成任务」。Bot 在右侧返回草稿。需要入库时，点「确认里程碑」填写判断并核对原文，或用「创建任务」填写确认后的任务内容。

本版复用 DS Bot 的独立会话，每个文档讨论只有一个 Bot 成员。原插件对私密 Bot 的会话权限继续生效。安装包基于 DS Bot v0.3.6，本地构建版本为 0.3.6-workbench.1。
