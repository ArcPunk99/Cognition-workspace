# 个人工作台 MVP 设计原型

讨论稿 · 2026-11-23 · 所属任务 [[MVP 设计]]

**打开一个进行中的任务，先看到上次定了什么、还有什么要讨论；对某条判断有疑问时，点它旁边的引文，直接看到谁在什么语境下说了什么。** 以「整体框架设计」的 158 轮对话和「MVP 设计」的 66 轮对话为原型样本。人负责判断，查轮次、摘原句、配链接交给 Agent。

## DSH 怎么接本地仓库

本版以 **DSH（DeepSeek Harness）为改造底座**。人在 DSH 中选项目、开任务、与 Bot 对话、看出处；Obsidian 打开同一批本地 Markdown，供人阅读、编辑和用 Bases 查看进度。早期设计里已经提出「基于 DSH 底座的一个插件」。具体扩展入口和本地文件权限待对照 DSH 实现验证。[[收敛个人工作台需求 - 对话全文#第 19 轮|最初的 DSH 设想]]

首次使用时，在 DSH 选择本机仓库 `E:\project\Project`。进入「个人工作台搭建 / MVP 设计」后，当前会话关联到仓库内的任务页相对路径。重新打开任务时，DSH 从文件读取最新内容；在 Obsidian 手工补写的笔记也能在 DSH 里看到。写入前若发现文件已被修改，先重读并合并本次追加。

| 在 DSH 里做的事 | 本地仓库里发生的事 |
| --- | --- |
| 给当前任务加入一段对话 | 全文保存在该任务目录，保留发言人和轮次。已有导出直接引用。 |
| 问某项设计为何这样定 | 从相关任务笔记取回原句、发言人和位置。DSH 当场展开前后文，也提供「在 Obsidian 打开原文」。 |
| 说「这条留下」并确认判断 | 写下确认内容及依据，链接采用库内文件名和轮次标题或段落标识。仅在界面里高亮的候选继续标作待确认。 |
| 确认交付 | 阶段成果保留在任务层；确认版本进入产物层，从任务页链接过去。Bot 一次运行结束时，任务仍按任务页的状态显示。 |

**加入对话。** 人在当前任务下贴分享链接或给本地文档。Agent 保存全文、保留发言人和轮次，并把本次讨论挂到当前话题。遇到已经导入的同一段对话，复用原文。同一任务可以继续接下一次讨论。[[收敛个人工作台需求 - 对话全文#第 48 轮|原型起点]]

**留下一条。** 人在对话中说“这条留下”，或事后一次选中几条。Agent 把判断、原句和来源放在一起。若“同意”指的是上一轮，摘录同时保留提案和回应。如果只有 Agent 提议，白板显示“待确认”；人明确确认后才作为共识交接。外部材料同理，Agent 给出值得读的段落，人读完后把自己的理解放回白板。[[收敛个人工作台需求 - 对话全文#第 26 轮|摘录与共识]] · [[收敛个人工作台需求 - 对话全文#第 61 轮|外部材料怎样形成判断]]

**回看依据。** 默认显示短引文，只有想核对时才打开全文。现有 Markdown 直接用轮次标题定位；一轮太长时，Agent 可以在本地导出副本的准确段落加块标识。链接定位到的引文必须能与原文对上。定位失败就显示“出处待核”，保留候选供人辨认。人的操作只有选和读。现有案例已经可以直接点回百轮对话里讨论 SQLite 的那一轮。[[构建个人工作台框架 - 对话全文#第 119 轮|查看当时提出的四条异议]]

**交给下一个 Agent。** 人点“输出本话题上下文”，得到一段可复制的 Markdown，依次列出任务目标、已确认判断及出处、待定问题、下一步。某条旧判断被明确修订时，交接使用新判断，同时留一条回看旧判断的链接。白板可以讨论完成，任务仍可进行；阶段产物保留版本，正式交付和任务收尾由人确认。[[收敛个人工作台需求 - 对话全文#第 58 轮|批量交接]] · [[构建个人工作台框架 - 对话全文#第 146 轮|阶段版本和历史]]

## 第一版怎样试

第一步在 DSH 绑定现有仓库，并打开「MVP 设计」任务。DSH 白板的摘录与出处写回该任务页，Obsidian Bases 继续读取现有属性展示进度。任务状态沿用库里的「待推进、进行中、已完成」。[[Schema|当前字段]]

用三个动作验收这份原型：

1. 从白板问“当初为什么建议第一版不用 SQLite”，点一次出处就到 158 轮材料里的具体讨论，能看见说话人和理由。
2. 在 DSH 确认一条摘录，打开 Obsidian，能看到同一条记录并跳到原话。在 Obsidian 为它补一句说明，重新打开 DSH 任务也能读到。
3. 换一个 Agent，只给它本话题输出的上下文，请它接着讨论溯源交互。它应能说出任务目标、引用已确认的要求，并指出仍需人决定的事。

首个可演示版本以这三个动作验收。开发前先在本机 DSH 核实三处接入点：怎样取得当前会话和消息、怎样绑定并读写指定仓库、怎样从引文打开本地笔记的具体位置。
